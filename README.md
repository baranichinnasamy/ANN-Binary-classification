# ANN-Binary-classification
1. ANN – Binary Classification using Make Moons
Project Description
This project implements an Artificial Neural Network (ANN) to classify data into two different categories using the make_moons dataset from Scikit-learn.
Objective
To understand how an Artificial Neural Network learns patterns from data and performs binary classification.
Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Scikit-learn
Implementation Steps
1. Import the required libraries.
2. Generate a two-class dataset using make_moons.
3. Split the dataset into training and testing data.
4. Build an ANN model with input, hidden and output layers.
5. Compile the model using the Adam optimizer and binary cross-entropy loss.
6. Train the model using the training dataset.
7. Evaluate the model using testing data.
8. Visualize the classification results and decision boundary.
